📥 What shuttlebay Does

shuttlebay helps your computer run Ruby web apps. These are applications built with common Ruby tools such as Rails, Sinatra, and Roda. Instead of dealing with a complicated setup, you use shuttlebay as the part that keeps your app running and ready to use.

The application is built around a native engine and a docking protocol. In simple terms, it receives requests from the web and passes them to your Ruby app. It uses preforked, threaded workers to handle work in the background. You do not need to manage those details yourself.

  • Runs Ruby web apps on Windows.
  • Works with Rails, Sinatra, and Roda apps.
  • Uses a Rust native engine for the heavy lifting.
  • Supports multithreading and preforking behind the scenes.
  • Acts as a Puma alternative and Rack server for Ruby apps.

✨ Main Features

shuttlebay focuses on the essentials so you can run your Ruby web app without extra steps.

  • Ruby app support: run apps made with Rails, Sinatra, and Roda.
  • Native engine: a Rust-powered core turns docking-protocol frames into app requests.
  • Preforked workers: the app prepares background workers so it can answer more than one request at a time.
  • Threaded handling: multiple tasks can be worked on together for smoother performance.
  • Rack-friendly: works as a Rack handler and Rack server for Ruby web apps.
  • Puma alternative: a different choice for running Ruby web apps on your computer.
  • Local connections: supports local socket connections used by Ruby apps.
